# EulaReader_Extensions

Plugin repository for Eula Reader. The app adds it on first launch, or add it by hand in More, Settings, Repositories:

```
https://raw.githubusercontent.com/KonekoSupremacy/EulaReader_Extensions/main/.dist/plugins.min.json
```

- `.dist/plugins.min.json` lists every plugin and its latest version
- plugin scripts live in `.js/src/plugins`, icons in `public/static`
- built from EulaReader_Extensions_Source with `./release.sh "summary"`
